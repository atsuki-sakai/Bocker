# クーポン機能 操作説明書

最終更新日: 2025年1月

## 1. 機能概要

### この機能が何をするか
クーポン機能は、美容サロンがお客様に対して割引クーポンを発行・管理できる機能です。新規顧客の獲得やリピーター顧客の来店促進、特定メニューのプロモーションなど、様々なマーケティング施策に活用できます。

### 対象ユーザーと用途
- **対象ユーザー**: サロンオーナー、店長、マネージャー
- **主な用途**:
  - 新規顧客向けの初回割引クーポン発行
  - リピーター向けの特別割引クーポン
  - 期間限定キャンペーンの実施
  - 特定メニューのプロモーション

### 利用可能なプラン
- **LITE プラン**: 最大5個のクーポン作成可能
- **PRO プラン**: 最大20個のクーポン作成可能

## 2. 画面構成と導線

### 機能の画面一覧
1. **クーポン一覧画面**: クーポンの一覧表示と管理
2. **クーポン作成画面**: 新しいクーポンの作成
3. **クーポン編集画面**: 既存クーポンの編集

### 各画面への導入経路
```
ダッシュボード
└── サイドメニュー「クーポン」
    └── クーポン一覧画面
        ├── 「クーポンを追加」ボタン → クーポン作成画面
        └── 各クーポンの「編集」ボタン → クーポン編集画面
```

## 3. 操作手順

### 3-1. 新規作成手順

#### ステップ1: クーポン一覧画面を開く
1. ダッシュボードのサイドメニューから「クーポン」をクリック
2. 画面右上の「クーポンを追加」ボタンをクリック

#### ステップ2: 基本情報の入力
1. **クーポン名**を入力（例：「新規顧客限定20%OFF」）
   - 分かりやすい名前を付けることで管理が楽になります
   
2. **クーポンコード**を入力（最大12文字）
   - お客様に伝えるコードです
   - 例：「NEWUSER20」「SUMMER2025」
   - ⚠️ **注意**: 一度作成したコードは後から変更した場合、既存のコードは使用できなくなります。

3. **割引タイプ**を選択
   - **パーセント割引**: 1〜100%の範囲で設定
   - **固定額割引**: ¥1〜¥99,999の範囲で設定

4. **対象顧客**を選択
   - **全ての顧客**: 誰でも使用可能
   - **初回利用のみ**: 初めて来店するお客様限定
   - **リピーター限定**: 2回目以降の来店客限定

#### ステップ3: 期間と利用条件の設定
1. **有効期限**を設定
   - 開始日: クーポンが使用可能になる日
   - 終了日: クーポンの有効期限（必ず未来の日付を選択）
   
2. **最大利用回数**を設定（0〜99,999回）
   - 0に設定すると無制限に使用可能
   - 例：先着100名様限定なら「100」と入力

#### ステップ4: メニューとステータスの設定
1. **有効/無効**を設定
   - 「有効」にチェックを入れると即座に使用可能になります
   - 準備段階では「無効」にしておくことをお勧めします

2. **除外メニュー**を設定（任意）
   - クーポンを適用したくないメニューを選択
   - 例：新メニューや高額メニューを除外

3. 画面下部の「作成」ボタンをクリックして完了

### 3-2. 編集・更新手順

1. クーポン一覧画面で編集したいクーポンの「編集」ボタンをクリック
2. 必要な項目を変更
   - ⚠️ **注意**: クーポンコードの変更は推奨されません（お客様への混乱を避けるため）
3. 変更内容を確認後、「更新」ボタンをクリック
4. 「クーポンを更新しました」のメッセージが表示されたら完了

### 3-3. 検索・フィルターの使い方

現在のバージョンでは、クーポン一覧画面に以下の情報が表示されます：
- ステータス（有効/無効）
- クーポン名
- クーポンコード
- 割引タイプと値
- 利用回数/最大利用回数

ページネーション機能により、10件ずつ表示されます。

### 3-4. 削除・非表示方法

#### クーポンの削除
1. クーポン一覧画面で削除したいクーポンの「削除」ボタンをクリック
2. 確認ダイアログで「削除」をクリック
3. ⚠️ **注意**: 削除すると復元できません。利用履歴も失われます

#### クーポンの無効化（推奨）
削除の代わりに無効化することをお勧めします：
1. 編集画面で「有効」のチェックを外す
2. 「更新」ボタンをクリック
3. 無効化されたクーポンは使用できなくなりますが、データは保持されます

## 4. 典型的な利用シナリオの例

### シナリオA: 新規顧客向け初回割引クーポン
1. **作成**: 「初回限定30%OFF」クーポンを作成
   - クーポンコード: FIRST30
   - 割引タイプ: パーセント割引（30%）
   - 対象顧客: 初回利用のみ
   - 最大利用回数: 0（無制限）
   
2. **配布**: ホームページやSNSでクーポンコードを告知

3. **利用**: お客様が予約時にクーポンコードを入力

4. **確認**: 予約詳細画面で適用されたクーポンを確認

### シナリオB: 期間限定サマーキャンペーン
1. **作成**: 「夏季限定¥1,000OFF」クーポンを作成
   - クーポンコード: SUMMER1000
   - 割引タイプ: 固定額割引（¥1,000）
   - 対象顧客: 全ての顧客
   - 有効期限: 7月1日〜8月31日
   - 最大利用回数: 200回

2. **除外設定**: 高額メニューや新メニューを除外リストに追加

3. **監視**: 利用回数を定期的にチェック

4. **終了**: 期限または最大利用回数に達したら自動的に使用不可に

### シナリオC: リピーター向け特別クーポン
1. **作成**: 「いつもありがとう20%OFF」クーポンを作成
   - クーポンコード: THANKS20
   - 割引タイプ: パーセント割引（20%）
   - 対象顧客: リピーター限定
   
2. **配布**: 来店回数の多いお客様にLINEで個別配信

3. **効果測定**: 利用状況を確認し、リピート率向上を確認

## 5. エラー・注意事項

### よくあるエラーと対処法

#### エラー: 「クーポンコードが既に存在します」
- **原因**: 同じクーポンコードが既に登録されている
- **対処法**: 別のクーポンコードを使用してください

#### エラー: 「プランの上限に達しました」
- **原因**: 作成可能なクーポン数の上限に達している
- **対処法**: 
  - 不要なクーポンを削除する
  - プランをアップグレードする

#### エラー: 「終了日は開始日より後の日付を選択してください」
- **原因**: 有効期限の設定が誤っている
- **対処法**: 終了日を開始日より後の日付に設定する

### 操作時の注意点

1. **クーポンコードの管理**
   - 一度お客様に配布したコードは変更しない
   - 分かりやすく覚えやすいコードを設定する
   - 大文字・小文字は区別されません

2. **割引設定の確認**
   - パーセント割引と固定額割引を間違えないよう注意
   - 100%割引は実質無料になるため慎重に設定

3. **除外メニューの設定忘れ**
   - 新メニューや高額メニューは除外設定を忘れずに
   - 「メニューとステータス」タブを必ず確認

4. **有効期限の設定**
   - 終了日を過ぎると自動的に使用不可になります
   - 編集時も必ず未来の日付を設定してください

5. **利用回数の管理**
   - 現在の利用回数は編集画面で確認可能（変更不可）
   - 上限に達すると自動的に使用不可になります

## 6. FAQ・補足

### よくある質問

**Q: クーポンを一時的に使用停止したい**
A: 編集画面で「有効」のチェックを外して更新してください。削除せずにデータを保持できます。

**Q: クーポンの利用履歴を確認したい**
A: 現在のバージョンでは、各クーポンの総利用回数のみ確認可能です。詳細な利用履歴機能は今後のアップデートで追加予定です。

**Q: 同じお客様が何度も使えるクーポンを作りたい**
A: 「対象顧客」を「全ての顧客」に設定し、「最大利用回数」を大きな数値または0（無制限）に設定してください。

**Q: クーポンコードを自動生成したい**
A: 現在は手動入力のみ対応しています。ランダムな文字列生成ツールなどをご活用ください。

**Q: クーポンをLINEで配信したい**
A: クーポンコードをコピーして、LINE配信機能でメッセージに含めて送信してください。

### 補足情報

#### プレビュー機能について
クーポン作成・編集画面では、右側にリアルタイムプレビューが表示されます。設定内容がどのように表示されるか確認しながら作成できます。

#### データの保存について
- 作成・更新ボタンを押すまでデータは保存されません
- ブラウザを閉じると入力内容は失われます
- 重要な設定は必ず保存を確認してください
