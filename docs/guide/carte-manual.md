# カルテ機能 詳細操作説明書

## 1. 機能概要

### この機能が何をするか
カルテ機能は、美容サロンで顧客の施術履歴や体質情報を一元管理するための機能です。顧客一人ひとりの肌質・髪質・アレルギー情報などの基本情報と、各施術時の詳細記録（写真・メモ・要望）を管理できます。

### 対象ユーザーと用途
- **対象ユーザー**: サロンスタッフ、オーナー
- **主な用途**:
  - 顧客の体質情報（肌質・髪質・アレルギー・病歴）の記録
  - 施術前後の写真記録（PROプラン以上）
  - 施術内容・顧客要望・スタッフメモの管理
  - 過去の施術履歴の確認
  - 音声入力による効率的なメモ作成（PROプラン以上）

## 2. 画面構成と導線

### 機能の画面一覧

1. **顧客検索画面**
   - パス: `/dashboard/carte`
   - 役割: カルテは予約に自動で作成・閲覧したい顧客を検索する画面

2. **顧客カルテ一覧画面**
   - パス: `/dashboard/carte/[customer_id]`
   - 役割: 選択した顧客の基本情報と施術履歴を表示

3. **カルテ基本情報編集画面**
   - パス: `/dashboard/carte/[customer_id]/edit`
   - 役割: 顧客の肌質・髪質・アレルギー・病歴を編集

4. **施術カルテ詳細画面**
   - パス: `/dashboard/carte/[customer_id]/reservation/[reservation_id]`
   - 役割: 特定の予約に対する施術記録の作成・編集

### アクセス方法
1. ダッシュボード → サイドメニュー「カルテ」をクリック
2. または、予約詳細画面から「カルテを見る」ボタンをクリック

## 3. 操作手順

### 3-1. 新規作成手順

#### カルテ基本情報の新規作成
1. カルテ画面から対象顧客を検索
2. 顧客名をクリックして顧客カルテ一覧画面へ
3. 右上の「編集」ボタンをクリック
4. 以下の情報を入力：
   - **肌質**: 普通肌/乾燥肌/脂性肌/混合肌/敏感肌から選択
   - **髪質**: ストレート/ウェーブ/カーリー/コイリー/細い/太いから選択
   - **アレルギー歴**: テキストで詳細を記入（最大1000文字）
   - **病歴**: テキストで詳細を記入（最大1000文字）
5. 「作成」ボタンをクリックして保存

#### 施術カルテの新規作成
カルテは予約の受付時に自動で作成されます。
1. 顧客カルテ一覧画面の「施術履歴」から該当予約をクリック
2. 施術カルテ詳細画面で以下を入力：
   - **施術後の写真**: 最大4枚まで（PROプラン以上）
   - **お客様のご要望**: 顧客から伺った要望を記録
   - **スタッフメモ**: 施術時の気づきや注意点を記録
3. 「保存する」ボタンをクリック

### 3-2. 編集・更新手順

#### カルテ基本情報の編集
1. 顧客カルテ一覧画面で「編集」ボタンをクリック
2. 変更したい項目を修正
3. 「更新」ボタンをクリックして保存

#### 施術カルテの編集
1. 施術履歴から編集したい予約をクリック
2. 各項目を編集：
   - **写真の追加**: ドラッグ&ドロップまたはクリックで選択
   - **写真の削除**: 既存写真の右上の×ボタンをクリック
   - **メモの編集**: テキストエリアで直接編集
   - **音声入力**: マイクボタンで音声入力（PROプラン以上）
3. 「保存する」ボタンをクリック

### 3-3. 検索・フィルターの使い方

#### 顧客検索
1. カルテ画面上部の検索ボックスに入力
2. 検索対象：
   - 顧客名（姓・名）
   - 電話番号
   - メールアドレス
   - LINE表示名
   - タグ
3. 入力後1秒で自動検索開始
4. 検索をクリアするには「クリア」ボタンをクリック

#### 検索のコツ
- ひらがな・カタカナは区別されません
- 部分一致で検索されます
- スペースで区切った複数キーワードはAND検索

### 3-4. 削除・非表示方法

**重要**: カルテデータは直接削除できません。これは施術履歴の保護のためです。

- 顧客をアーカイブすると、カルテ検索結果に表示されなくなります
- アーカイブは「顧客管理」画面から行います

## 4. 典型的な利用シナリオの例

### シナリオA: 新規顧客の初回施術
1. 予約受付時に顧客情報を登録
2. 来店時にカルテ基本情報を作成
   - カウンセリングで肌質・髪質を確認
   - アレルギーの有無を聞き取り
3. 施術後、カルテ詳細を記録
   - ビフォーアフター写真を撮影（お客様の許可を得て）
   - 使用した薬剤や施術内容をメモ
   - 次回への申し送り事項を記載

### シナリオB: リピーター顧客の施術
1. 来店前に過去のカルテを確認
   - 前回の施術内容・要望を把握
   - アレルギー情報を再確認
2. 施術中に気づいた点をメモ
   - 音声入力で手が塞がっていても記録可能
3. 施術後の状態を写真で記録
   - 前回との比較が可能

### シナリオC: スタッフ間の情報共有
1. 担当変更時に過去のカルテを確認
2. 重要な注意事項（アレルギー等）を把握
3. 顧客の好みや要望を引き継ぎ

## 5. エラー・注意事項

### よくあるエラーと対処法

#### 「顧客情報が見つかりません」
- **原因**: URLを直接入力した、または顧客が削除された
- **対処**: カルテ検索画面から正しい顧客を選択

#### 「データの取得に失敗しました」
- **原因**: ネットワークエラーまたはサーバーエラー
- **対処**: 
  1. インターネット接続を確認
  2. ページを再読み込み
  3. 問題が続く場合はサポートに連絡

#### 「画像のアップロードに失敗しました」
- **原因**: ファイルサイズが大きすぎる、またはネットワークエラー
- **対処**: 
  1. 画像サイズを6MB以下に圧縮
  2. 一度に4枚以下でアップロード
  3. Wi-Fi環境で再試行

### 操作時の注意点

#### データ保存について
- **自動保存はされません** - 必ず「保存する」ボタンをクリック
- 保存前にページを離れると入力内容が失われます
- 保存ボタンは変更があった場合のみ有効になります

#### 写真管理について
- 施術後写真は最大4枚まで
- 一度削除した写真は復元できません
- お客様の許可なく写真を撮影・保存しないこと

#### プライバシーとセキュリティ
- カルテ情報は機密情報として扱う
- 個人を特定できる写真の取り扱いに注意
- 不要な個人情報は記載しない

## 6. FAQ・補足

### よくある質問

**Q: LITEプランでもカルテ機能は使えますか？**
A: 基本的なカルテ機能（肌質・髪質・アレルギー・病歴・テキストメモ）は全プランで利用可能です。写真アップロードと音声入力はPROプラン以上で利用できます。

**Q: 過去のカルテを一括でダウンロードできますか？**
A: 現在、一括ダウンロード機能は提供していません。個別の施術記録は画面から確認・印刷可能です。

**Q: 複数スタッフで同時編集できますか？**
A: 同じカルテを複数人で同時編集すると、最後に保存した内容で上書きされます。編集時は他スタッフと調整してください。

**Q: カルテデータはいつまで保存されますか？**
A: カルテデータは2年間保存されます。

**Q: 写真の画質が悪くなることがあります**
A: アップロード時に自動的に圧縮処理が行われます。元画像は高画質で撮影し、重要な部分が見えるようにしてください。

### 便利な使い方のヒント

1. **テンプレート文の活用**
   - よく使うフレーズはメモ帳に保存しておき、コピー&ペーストで効率化

2. **写真撮影のコツ**
   - 同じアングル・照明で撮影すると比較しやすい
   - 施術部位がはっきり見えるように撮影

3. **検索の活用**
   - タグ機能を使って「カラー希望」「パーマNG」など分類
   - 定期的に来店する顧客は検索しやすい名前でタグ付け

4. **スタッフ間の連携**
   - 重要事項は【重要】マークを付けて目立たせる
   - 次回予約時の注意点は必ずメモに残す
