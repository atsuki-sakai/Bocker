# ポイント機能 操作説明書

最終更新日: 2025年6月28日

## 1. 機能概要

### この機能が何をするか
ポイント機能は、美容サロンの顧客に対して、施術利用金額に応じてポイントを自動付与し、次回以降の施術で「1ポイント = 1円」として利用できるリピート促進システムです。

### 対象ユーザーと用途
- **サロンオーナー**: ポイント付与率や有効期限などの基本設定を行います
- **サロンスタッフ**: 予約受付時に顧客のポイント利用を処理します
- **顧客**: 予約時にポイントを使用して割引を受けられます

### 主な特徴
- 施術完了の30日後に自動でポイント付与
- 有効期限の自動管理（1年/2年/3年から選択可能）
- ポイント使用・付与の履歴管理
- 予約キャンセル時の自動返還機能

## 2. 画面構成と導線

### 機能の画面一覧
1. **ポイント設定画面**（オーナー専用）
   - アクセス方法: ダッシュボード → サイドバー「ポイント設定」
   - URL: `/dashboard/point`

2. **予約作成画面**（スタッフ用）
   - アクセス方法: ダッシュボード → 「予約作成」
   - ポイント使用は予約フローの「支払い方法選択」ステップで行います

3. **顧客マイページ**（顧客用）
   - アクセス方法: 顧客専用URL → ログイン → 「ポイント」
   - URL: `/customer/[org_id]/[uid]/point`

## 3. 操作手順

### 3-1. ポイント機能の初期設定（オーナー向け）

#### ステップ1: ポイント設定画面へアクセス
1. ダッシュボードにログイン
2. 左側のサイドバーから「ポイント設定」をクリック

#### ステップ2: 基本設定を行う

**ポイント機能の有効化**
1. 「ポイント機能は無効」と表示されている場合、スイッチをONにする
2. スイッチがONになると「ポイント機能は有効」と緑色で表示される

**ポイント付与タイプの選択**
- **率指定タイプ（推奨）**: 利用金額の○％をポイント付与
  - 例: 5%設定の場合、10,000円の施術で500ポイント付与
- **固定ポイントタイプ**: 金額に関わらず一律のポイント付与
  - 例: 100ポイント固定の場合、施術金額に関わらず100ポイント付与

**ポイント付与率/固定ポイントの設定**
- 率指定の場合: 0～100%の間で設定（推奨: 3～10%）
- 固定ポイントの場合: 1～99,999ポイントの間で設定

**ポイント有効期限の選択**
- 1年、2年、3年から選択可能
- デフォルトは1年に設定されています

#### ステップ3: 設定内容の確認と保存
1. 右側の「ポイント設定概要」で設定内容を確認
2. サンプル計算（1,000円、5,000円の決済時）が表示される
3. 問題なければ「設定を保存」ボタンをクリック

### 3-2. 予約時のポイント使用（スタッフ向け）

#### ステップ1: 通常通り予約作成を進める
1. 顧客選択 → メニュー選択 → スタッフ選択 → 日時選択

#### ステップ2: 支払い方法選択画面でポイント使用
1. 「支払い方法」ステップに進む
2. 顧客の保有ポイントが自動表示される
3. 「使用ポイント」のスライダーを動かすか、直接数値を入力
4. 最大使用可能ポイントは「合計金額」または「保有ポイント」の小さい方

#### ステップ3: 予約確定
1. ポイント使用後の支払い金額を確認
2. 「予約を確定」ボタンをクリック
3. ポイントが即座に顧客の残高から引かれる

### 3-3. ポイント付与の流れ（自動処理）

**付与タイミング**
- 予約日時（施術完了）から30日後に自動付与
- バッチ処理により毎時間チェックされる

**付与条件**
1. 予約ステータスが「完了」であること
2. ポイント機能が有効であること
3. 付与予定日時を過ぎていること

### 3-4. 予約キャンセル時の処理

**顧客都合のキャンセル**
1. 使用済みポイントは自動的に返還される
2. 付与予定のポイントはキャンセルされる
3. 履歴に「予約キャンセルによるポイント返還」として記録

**店舗都合のキャンセル**
- 顧客都合と同様の処理が行われる

## 4. 典型的な利用シナリオの例

### シナリオA: 新規顧客の初回来店からポイント付与まで

1. **初回来店（4月15日）**
   - カット+カラー 10,000円の施術
   - ポイント付与率5%設定
   - 500ポイント付与予定として記録

2. **30日後（5月15日）**
   - 自動バッチ処理により500ポイント付与
   - 顧客にLINE/メール通知
   - 「500ポイントが付与されました」

3. **2回目来店時**
   - 保有ポイント500ポイントを確認
   - 施術料金8,000円に対して500ポイント使用
   - 支払額7,500円

### シナリオB: 常連顧客のポイント活用パターン

1. **定期来店（毎月）**
   - 毎月5,000円の施術
   - 5%付与で毎月250ポイント獲得
   - 年間3,000ポイント蓄積

2. **特別な施術時**
   - パーマ+トリートメント 15,000円
   - 蓄積した3,000ポイントを使用
   - 実質12,000円で施術

## 5. エラー・注意事項

### よくあるエラーと対処法

**エラー1: 「ポイント設定が見つかりません」**
- 原因: ポイント機能が未設定
- 対処: オーナー権限でポイント設定画面から初期設定を行う

**エラー2: 「ポイントが不足しています」**
- 原因: 使用しようとしたポイントが保有ポイントを超えている
- 対処: 使用ポイント数を保有ポイント以下に調整

**エラー3: 「ポイント処理でエラーが発生しました」**
- 原因: システムエラーまたはネットワークエラー
- 対処: 予約は正常に作成されるため、後日手動でポイント調整

### 操作時の注意点

1. **設定変更の影響**
   - ポイント付与率の変更は即座に反映される
   - 既に付与予定のポイントには影響しない

2. **ポイントの二重付与防止**
   - ポイントを使用した金額部分には新たなポイントは付与されない
   - 例: 10,000円の施術で2,000ポイント使用 → 8,000円分のみポイント付与対象

3. **有効期限の管理**
   - 有効期限は最後の利用日から起算される
   - 期限切れポイントは自動的に失効する

4. **データの保存**
   - 設定変更は必ず「設定を保存」ボタンをクリック
   - 保存前にページを離れると変更が失われる

## 6. FAQ・補足

### よくある質問

**Q1: ポイントはいつ付与されますか？**
A: 施術完了から30日後に自動的に付与されます。これは顧客の満足度確認期間として設定されています。

**Q2: ポイントの有効期限はどう計算されますか？**
A: 最後にサロンを利用した日から、設定した期間（1年/2年/3年）後に失効します。新たに来店すると、全ポイントの有効期限が延長されます。

**Q3: 他店舗でポイントは使えますか？**
A: いいえ、ポイントは付与された店舗でのみ使用可能です。

**Q4: ポイントを現金に換金できますか？**
A: できません。ポイントは施術料金の支払いにのみ使用可能です。

**Q5: 付与率を途中で変更したらどうなりますか？**
A: 新規予約から新しい付与率が適用されます。既存の付与予定ポイントは変更されません。

### 補足情報

**会計処理について**
- 未使用ポイントは「ポイント引当金」として負債計上することを推奨
- 税務上は使用時に売上値引きとして処理

**マーケティング活用**
- ポイント2倍キャンペーン: 一時的に付与率を上げる
- 失効前通知: 7-14日前にリマインド送信で来店促進
- 誕生月ボーナス: 手動でポイント付与も可能

**システム連携**
- LINE通知: ポイント付与時に自動通知
- 顧客マイページ: リアルタイムで残高確認可能
- レポート機能: ポイント利用状況の分析可能

**トラブルシューティング**
問題が解決しない場合は、以下の情報を準備してサポートに連絡：
- テナントID・組織ID
- エラーメッセージのスクリーンショット
- 発生日時と操作内容
- 影響を受けた顧客ID・予約ID
