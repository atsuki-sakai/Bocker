# メニュー機能 操作説明書

## 1. 機能概要

### この機能が何をするか
メニュー機能は、美容サロンで提供するサービスメニューを管理するための機能です。メニューの作成、編集、価格設定、カテゴリ分類、画像登録など、サービスメニューに関する全ての情報を一元管理できます。

### 対象ユーザーと用途
- **サロンオーナー**: メニューの作成・価格設定・公開管理
- **スタッフ**: メニュー情報の確認・予約時のメニュー選択
- **顧客**: 予約時にメニューを選択（LINE予約システム経由）

## 2. 画面構成と導線

### 機能の画面一覧
1. **メニュー一覧画面** (`/dashboard/menu`)
   - 登録済みメニューの一覧表示
   - メニューの検索・フィルタリング
   - 新規作成ボタン

2. **メニュー新規作成画面** (`/dashboard/menu/add`)
   - メニュー情報の入力フォーム
   - 画像アップロード
   - 保存・キャンセルボタン

3. **メニュー詳細画面** (`/dashboard/menu/[menu_id]`)
   - メニュー情報の詳細表示
   - 編集・削除ボタン

4. **メニュー編集画面** (`/dashboard/menu/[menu_id]/edit`)
   - メニュー情報の編集フォーム
   - 画像の追加・削除
   - 更新・キャンセルボタン

### 各画面への導線
- **ダッシュボード** → サイドメニュー「メニュー」→ **メニュー一覧画面**
- メニュー一覧画面 → 「新規作成」ボタン → **メニュー新規作成画面**
- メニュー一覧画面 → メニュー項目クリック → **メニュー詳細画面**
- メニュー詳細画面 → 「編集」ボタン → **メニュー編集画面**

## 3. 操作手順

### 3-1. 新規作成手順

#### ステップ1: 基本情報の入力
1. メニュー一覧画面で「新規作成」ボタンをクリック
2. 以下の必須項目を入力：
   - **メニュー名**: サービス名を入力（例：カット、カラー、パーマ）
   - **カテゴリ**: 1つ以上選択（最大5つまで）
   - **価格**: 通常価格を入力（1円〜999,999円）
   - **所要時間**: 5分単位で選択（5分〜360分）
   - **説明文**: メニューの詳細説明を入力

#### ステップ2: 画像の登録（任意）
1. 画像エリアをクリックまたはドラッグ&ドロップ
2. 最大3枚まで登録可能（1枚あたり最大6MB）
3. 対応形式：JPG、PNG、WebP、GIF

#### ステップ3: 詳細設定
1. **セール価格**（任意）: キャンペーン価格を設定
2. **ターゲット設定**:
   - 対象顧客: 全員/初回のみ/リピーターのみ
   - 性別: 全性別/男性のみ/女性のみ
3. **タグ**（任意）: 検索用キーワードを最大5つまで設定
4. **支払い方法**: 
   - 店頭決済のみ
   - オンライン決済のみ
   - 両方対応

#### ステップ4: 公開設定と保存
1. 「メニューを公開する」スイッチで公開/非公開を設定
2. 「メニューを追加」ボタンをクリックして保存

### 3-2. 編集・更新手順

1. メニュー一覧画面から編集したいメニューをクリック
2. メニュー詳細画面で「編集」ボタンをクリック
3. 編集画面で情報を修正：
   - **画像の変更**: 既存画像の削除、新規画像の追加、順序変更が可能
   - **価格変更**: 通常価格・セール価格の変更
   - **その他**: 全ての項目が編集可能
4. 「更新」ボタンをクリックして保存

### 3-3. 検索・フィルターの使い方

#### メニュー一覧での検索
1. 検索バーにキーワードを入力
2. メニュー名、価格、タグで検索可能
3. リアルタイムで結果が絞り込まれる

#### カテゴリフィルター（予約画面）
1. 「カテゴリを絞り込む」ボタンをクリック
2. 表示したいカテゴリにチェック
3. 複数選択可能、選択したカテゴリのメニューのみ表示

### 3-4. 削除・非表示方法

#### メニューの削除
1. メニュー詳細画面で「削除」ボタンをクリック
2. 確認ダイアログで「削除する」をクリック
3. **注意**: 削除したメニューは復元できません

#### メニューの非表示
1. メニュー編集画面で「メニューを公開する」スイッチをOFF
2. 「更新」ボタンをクリック
3. 非表示のメニューは予約画面に表示されません

## 4. 典型的な利用シナリオの例

### シナリオA: 新メニューの追加から予約受付まで
1. 新しいトリートメントメニューを作成
2. 画像3枚を登録（施術前後の写真など）
3. カテゴリ「トリートメント」を選択
4. 価格5,000円、所要時間60分を設定
5. 「髪質改善」「ダメージケア」などのタグを追加
6. 公開設定をONにして保存
7. 顧客が予約時にメニューを選択可能に

### シナリオB: セットメニューの作成
1. 「カット＋カラー」などの複合メニューを作成
2. 複数のカテゴリ（カット、カラー）を選択
3. セット価格を設定（個別より割引価格）
4. 所要時間は合計時間を設定
5. 予約時は「セットメニュー」として表示

### シナリオC: 期間限定キャンペーンの設定
1. 既存メニューの編集画面を開く
2. セール価格を設定（例：通常5,000円→4,000円）
3. タグに「期間限定」を追加
4. 更新して保存
5. 予約画面では割引価格が強調表示

## 5. エラー・注意事項

### よくあるエラーと対処法

#### エラー：「画像のアップロードに失敗しました」
- **原因**: ファイルサイズが6MBを超えている
- **対処**: 画像を圧縮してから再度アップロード

#### エラー：「メニュー名は必須です」
- **原因**: メニュー名が未入力
- **対処**: メニュー名を入力してから保存

#### エラー：「セール価格は通常価格より低く設定してください」
- **原因**: セール価格が通常価格以上に設定されている
- **対処**: セール価格を通常価格より低く設定

### 操作時の注意点

1. **画像の順序**
   - 1枚目の画像がサムネイルとして使用される
   - ドラッグ&ドロップで順序変更可能

2. **カテゴリ設定**
   - 複数カテゴリを選択するとセットメニューとして扱われる
   - セットメニュー選択時は、含まれるカテゴリの個別メニューは選択不可

3. **価格設定**
   - オンライン決済を有効にするには決済設定が必要
   - 決済手数料は自動的に計算される

4. **データの保存**
   - 編集中のデータは自動保存されない
   - ページを離れる前に必ず「保存」または「更新」ボタンをクリック

## 6. FAQ・補足

### よくある質問

**Q: メニューは何個まで作成できますか？**
A: プランによって上限が異なります。
- スタータープラン：20個まで
- スタンダードプラン：50個まで
- プレミアムプラン：無制限

**Q: 削除したメニューを復元できますか？**
A: 削除したメニューは復元できません。非表示機能の利用をお勧めします。

**Q: 画像なしでメニューを作成できますか？**
A: はい、画像は任意項目です。後から追加することも可能です。

**Q: セットメニューの価格は自動計算されますか？**
A: いいえ、セットメニューの価格は手動で設定する必要があります。

**Q: タグはどのように活用されますか？**
A: 顧客の予約画面での検索や、スタッフのメニュー管理で使用されます。

### 補足情報

#### オンライン決済の設定方法
1. ダッシュボード → 設定 → 決済設定
2. Stripe Connectの設定を完了
3. メニューの支払い方法で「オンライン決済」を選択可能に

#### メニューカテゴリの追加依頼
- 新しいカテゴリが必要な場合は bocker.help@gmail.com までご連絡ください
- リクエストを検討し、全ユーザー向けに追加されます

#### 推奨される画像サイズ
- 推奨サイズ：800×1200px（縦長）
- 最小サイズ：400×600px
- ファイル形式：WebP推奨（自動変換されます）
