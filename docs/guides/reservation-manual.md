# 予約管理機能 操作マニュアル

このマニュアルでは、Bockerの予約管理機能について、具体的な操作方法や注意点をご案内します。  
サロンスタッフ様とお客様の両方の視点から、実際の画面イメージを交えながら丁寧に説明いたします。

---

## 1. 機能概要

### 予約管理機能とは

予約管理機能は、美容サロンにおける予約の作成・管理・キャンセルを効率的に行うための総合システムです。  
リアルタイムでの空き状況確認、自動在庫管理、決済連携など、予約に関わるあらゆる業務をサポートします。

### 対象ユーザーと用途

#### **サロンスタッフ向け（管理画面）**

- **サロンオーナー**: 全体の予約状況把握、売上管理、スタッフシフト調整
- **スタッフ**: 自分の予約確認、顧客対応、施術準備
- **受付担当**: 電話・対面での予約受付、変更対応、決済処理

#### **お客様向け（Web予約）**

- **予約の確認**: 自分の予約内容、日時、担当スタッフの確認
- **予約のキャンセル**: 期限内での予約キャンセル
- **履歴の確認**: 過去の施術履歴、支払い履歴の確認

### 主な機能一覧

- タイムライン形式での予約一覧表示
- リスト形式での予約一覧表示
- 新規予約作成（現金・クレジットカード決済対応）
- 予約の詳細確認・編集
- 予約のキャンセル（在庫自動復元）
- クーポン・ポイント適用
- メール・LINE通知の自動送信
- オプション在庫管理
- スタッフ別予約管理

## 2. 画面構成と導線

### サロンスタッフ向け管理画面の構成

#### **メニューからのアクセス**

1. ダッシュボードのサイドメニューから「予約」をクリック
2. 以下の画面にアクセスできます：
   - **予約タイムライン画面** (`/dashboard/reservation`)
   - **予約詳細画面** (`/dashboard/reservation/[予約ID]`)
   - **新規予約作成画面** (`/dashboard/reservation/add`)
   - **予約収集画面** (`/dashboard/reservation/collection`) ※決済待ち一覧

### お客様向け予約確認画面の構成

#### **予約確認へのアクセス**

1. 予約完了メールのリンクから
2. LINEからの通知リンクから
3. マイページの予約履歴から

#### **お客様向け画面**

- **予約履歴一覧** (`/customer/[組織ID]/[顧客ID]/reservation`)
- **予約詳細画面** (`/customer/[組織ID]/[顧客ID]/reservation/[予約ID]`)

## 3. 操作手順

### 3-1. 新規予約作成手順

#### **管理画面から予約を作成する場合**

1. **予約作成画面を開く**

   - サイドメニューの「予約」→「予約を追加」をクリック
   - またはタイムライン画面右上の「新規予約」ボタンをクリック

2. **顧客情報の入力**

   - **既存顧客の場合**
     - 「既存のお客様」を選択
     - 顧客検索ボックスで名前や電話番号を入力
     - 該当顧客を選択
   - **新規顧客の場合**
     - 「新規のお客様」を選択
     - 姓・名（必須）
     - 電話番号（必須）
     - その他の情報（任意）

3. **予約日時の選択**

   - カレンダーから予約日を選択
   - 開始時間をプルダウンから選択
   - 終了時間は選択したメニューから自動計算

4. **スタッフの選択**

   - 担当スタッフをプルダウンから選択
   - 指名料がある場合は自動的に加算されます

5. **メニューの選択**

   - メニュー一覧から施術内容を選択
   - 複数メニューの選択が可能
   - 各メニューの数量を調整（＋/－ボタン）
   - セール価格が設定されている場合は自動適用

6. **オプションの選択**（任意）

   - 必要に応じてオプションを追加
   - 在庫がある場合のみ選択可能
   - 在庫数が表示されるので確認しながら選択

7. **料金計算とクーポン・ポイント適用**

   - **基本料金**: メニュー料金 + オプション料金 + 指名料
   - **クーポン適用**（任意）
     - 利用可能なクーポンから選択
     - 割引額が自動計算されます
   - **ポイント使用**（任意）
     - 使用するポイント数を入力
     - 顧客の保有ポイント以内で設定

8. **支払い方法の選択**

   - **現金決済**: その場で支払い完了
   - **クレジットカード決済**: Stripe決済ページへ誘導

9. **備考の入力**（任意）

   - 特記事項やお客様からの要望を記入

10. **予約の確定**
    - 「予約を作成」ボタンをクリック
    - 確認画面で内容を最終確認
    - 問題なければ「確定」をクリック

> 💡 **ヒント**:
>
> - 時間の重複チェックは自動で行われます
> - オプションの在庫は予約作成時点で即座に減算されます
> - クレジットカード決済の場合、30分以内に決済が完了しないと自動キャンセルされます

### 3-2. 予約の確認・編集手順

#### **タイムライン表示での確認**

1. **タイムライン画面を開く**

   - サイドメニューの「予約」をクリック
   - デフォルトでタイムライン表示になります

2. **日付の選択**

   - カレンダーアイコンから確認したい日付を選択
   - 左右の矢印で前後の日付に移動
   - 「今日」ボタンで当日に戻る

3. **予約の確認**

   - 横軸: 5:00〜翌5:00の時間軸（30分刻み表示）
   - 縦軸: スタッフ別の予約状況
   - 予約ブロックをクリックで詳細表示

4. **ステータスの見分け方**
   - 🟦 青色: 予約受付済み（confirmed）
   - 🟨 黄色: 保留中（pending）※決済待ち
   - 🟥 赤色: キャンセル済み（cancelled）
   - 🟩 緑色: 完了（completed）

#### **リスト表示での確認**

1. **表示切り替え**

   - 画面上部の「リスト」タブをクリック

2. **予約一覧の確認**
   - 時系列で予約が表示されます
   - 各予約カードには以下が表示：
     - 顧客名
     - 時間帯
     - 担当スタッフ
     - ステータス

#### **予約詳細の確認**

1. **詳細画面へのアクセス**

   - タイムラインまたはリストで予約をクリック
   - ポップアップの「詳細を見る」をクリック

2. **確認できる情報**
   - 顧客情報（名前、連絡先）
   - 予約日時
   - メニュー・オプション内容
   - 料金明細
   - クーポン・ポイント使用状況
   - 支払い状況
   - 備考・メモ

### 3-3. 予約のキャンセル手順

#### **スタッフによるキャンセル**

1. **予約詳細画面を開く**

   - キャンセルしたい予約の詳細画面へ移動

2. **キャンセルボタンをクリック**

   - 画面下部の「予約をキャンセル」ボタンをクリック

3. **キャンセル理由の入力**

   - キャンセル理由を選択または入力
   - 「キャンセルを確定」をクリック

4. **自動処理**
   - オプション在庫が自動的に復元されます
   - ポイント付与予定がある場合は自動削除
   - 顧客へキャンセル通知メールが送信されます

#### **お客様によるキャンセル**

1. **予約詳細画面へアクセス**

   - メールやLINEのリンクから
   - またはマイページから

2. **キャンセル可能期限の確認**

   - キャンセル期限が表示されています
   - 通常は予約日の1日前まで

3. **キャンセル実行**
   - 「予約をキャンセル」ボタンをクリック
   - 確認画面で「キャンセルする」をクリック

> ⚠️ **注意**:
>
> - キャンセル期限を過ぎるとお客様自身ではキャンセルできません
> - スタッフは期限に関係なくキャンセル可能です
> - クレジットカード決済済みの場合、返金処理が必要な場合があります

### 3-4. 決済処理の流れ

#### **現金決済の場合**

1. 予約作成時に「現金」を選択
2. 予約が即座に「確定」ステータスになります
3. 来店時に現金で支払いを受けます
4. 30日後に自動的にポイントが付与されます

#### **クレジットカード決済の場合**

1. 予約作成時に「クレジットカード」を選択
2. 予約が「保留」ステータスで作成されます
3. お客様がStripe決済ページで支払い
4. 決済成功後、自動的に「確定」ステータスに変更
5. 決済完了通知メールが送信されます

## 4. 典型的な利用シナリオの例

### シナリオA: 電話予約の受付

1. **お客様から電話で予約依頼**

   - 希望日時とメニューを確認

2. **空き状況の確認**

   - タイムライン画面で該当日時を確認
   - スタッフの空き時間を確認

3. **予約の作成**

   - 新規予約作成画面へ
   - 顧客情報を検索・入力
   - メニューとスタッフを選択
   - 現金決済を選択

4. **予約確定の連絡**
   - 確認メールまたはLineが自動送信されます

### シナリオB: リピーター様の次回予約

1. **施術終了後のお会計時**

   - カルテ画面から「次回予約を作成」をクリック

2. **前回と同じメニューで予約**

   - 前回の内容が自動的に入力される
   - 日時のみ変更して予約作成

3. **ポイント使用の提案**

   - 保有ポイントを確認
   - 次回使用可能なポイントを案内

4. **予約カードの発行**
   - 予約内容を印刷してお渡し

### シナリオC: 団体予約の受付

1. **複数名の同時予約**

   - 各人ごとに個別の予約を作成

2. **時間調整**

   - 開始時間をずらして効率的に配置
   - スタッフを分散して対応

3. **グループ割引の適用**
   - クーポンを使用して割引適用
   - 合計金額を計算

## 5. エラー・注意事項

### よくあるエラーと対処法

#### **「この時間帯の予約はすでにいっぱいです」**

- **原因**: 選択した時間帯に他の予約が入っている
- **対処**: 別の時間帯またはスタッフを選択

#### **「在庫が不足しています」**

- **原因**: オプションの在庫数が不足
- **対処**: 数量を減らすか、別のオプションを選択

#### **「決済に失敗しました」**

- **原因**: クレジットカードの問題
- **対処**: カード情報を確認し、再度決済を試みる

#### **「キャンセル期限を過ぎています」**

- **原因**: お客様のキャンセル可能期限を超過
- **対処**: スタッフが代理でキャンセル処理を行う

### 操作時の注意点

1. **予約作成時**

   - 営業時間外の予約は作成できません
   - スタッフの勤務時間を必ず確認
   - オプション在庫は即座に減算されるため慎重に

2. **キャンセル時**

   - キャンセル理由は必ず記録する
   - 決済済みの場合は返金処理を確認
   - 当日キャンセルは電話連絡も併用

3. **料金計算**

   - クーポンとポイントの併用可否を確認
   - 端数処理は自動で行われます
   - 領収書発行時は正確な金額を確認

4. **データの整合性**
   - 30分ごとの自動保存機能あり
   - ブラウザを閉じても作業内容は保持
   - 複数タブでの同時編集は避ける

## 6. FAQ・補足

### よくある質問

**Q: 予約の変更はできますか？**
A: 現在のシステムでは予約の直接変更はできません。一度キャンセルして新規作成してください。

**Q: 過去の予約を確認したい**
A: 顧客詳細画面の「予約履歴」タブから全履歴を確認できます。

**Q: 予約確認メールが届かない**
A: 顧客情報のメールアドレスが正しいか確認してください。迷惑メールフォルダも確認を。

**Q: ダブルブッキングを防ぐには？**
A: システムが自動的に重複チェックを行います。警告が出た場合は時間を調整してください。

**Q: キャンセル料は取れますか？**
A: 現在のシステムではキャンセル料の自動徴収機能はありません。別途対応が必要です。

### 補足情報

#### **予約に関する設定変更**

- 営業時間の設定: 設定 → 組織情報 → 営業時間
- キャンセル期限の設定: 設定 → 予約設定 → キャンセル可能日数
- スタッフの勤務時間: スタッフ管理 → 各スタッフの勤務スケジュール

#### **通知設定**

- メール通知: 自動送信（設定変更不可）
- LINE通知: LINE連携済みの顧客のみ
- リマインダー: 予約前日に自動送信

#### **レポート機能**

- 日別予約集計: ダッシュボードで確認
- スタッフ別稼働率: レポート画面で確認
- 売上分析: 決済レポートで確認

### トラブルシューティング

**画面が正しく表示されない場合**

1. ブラウザのキャッシュをクリア
2. 別のブラウザで試す
3. インターネット接続を確認

**予約が作成できない場合**

1. 必須項目がすべて入力されているか確認
2. 営業時間内の時間を選択しているか確認
3. スタッフの出勤状況を確認

**決済が完了しない場合**

1. カード情報が正しいか確認
2. 利用限度額を確認
3. 3Dセキュア認証を完了させる
