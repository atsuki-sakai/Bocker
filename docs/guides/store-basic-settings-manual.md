# 店舗の基本設定操作マニュアル

## 1. 機能概要

### この機能が何をするか
店舗の基本設定機能は、Bocker（ブッカー）でサロン運営に必要な基本情報、営業時間、予約ルール、LINE連携、決済設定などを一元管理するための中核機能です。この設定が適切に行われることで、お客様への適切な予約サービスの提供が可能になります。

### 対象ユーザーと用途
- **対象ユーザー**: サロンオーナー、店舗管理者
- **主な用途**:
  - 店舗の基本情報（名称、住所、連絡先）の登録・更新
  - 営業時間と定休日の設定
  - 予約受付ルールの設定
  - LINE公式アカウントとの連携設定
  - Stripeによるクレジットカード決済の設定

## 2. 画面構成と導線

### 機能の画面一覧
設定画面は6つのタブで構成されています：
1. **基本設定タブ** - 店舗の基本情報
2. **API設定タブ** - LINE連携の設定
3. **予約設定タブ** - 予約受付ルール
4. **営業時間タブ** - 曜日別営業時間
5. **休業日設定タブ** - 特別な休業日
6. **決済設定タブ** - Stripe決済連携

### 各画面の役割と導入経路
**アクセス方法**: ダッシュボードのサイドメニュー → 「設定」をクリック

各タブをクリックすることで、それぞれの設定画面に切り替わります。

## 3. 操作手順

### 3-1. 基本設定

#### 新規作成・編集手順

1. **店舗基本情報の入力**
   - **サロン名**: 店舗の正式名称を入力（最大120文字）
   - **メールアドレス**: 店舗の連絡用メールアドレス（任意）
   - **電話番号**: 8〜11桁の数字で入力（ハイフンなし）
   - **郵便番号**: 7桁の数字を入力すると住所が自動入力されます
   - **住所**: 郵便番号から自動入力、または手動で修正

2. **店舗画像の設定**
   - 「画像をドラッグ&ドロップ」エリアに画像をドロップ
   - または「ファイルを選択」をクリックして画像を選択
   - 推奨: 横長（16:9）の画像、最大5MB
   - 「画像を保存」ボタンをクリックして保存

3. **店舗説明・予約ルールの設定**
   - **店舗説明**: お客様に向けた店舗の紹介文（最大2000文字）
   - **予約ルール**: キャンセルポリシーなどの注意事項（最大2000文字）

4. **保存**
   - 入力内容を確認後、画面右下の「保存」ボタンをクリック
   - 変更がない場合、保存ボタンは無効化されます

### 3-2. API設定（LINE連携）

#### LINE連携の前準備
LINE連携には以下の2つのチャンネルが必要です：
1. **Messaging APIチャンネル** - メッセージ送信用
2. **LINEログインチャンネル** - 顧客ログイン用

#### 設定手順

1. **LINE公式アカウントの作成**
   - [LINE公式アカウントマネージャー](https://manager.line.biz/)にアクセス
   - サロン運営者本人のLINEアカウントでログイン
   - 「アカウントを作成」から新規作成

2. **Messaging APIチャンネルの作成**
   - [LINE Developers コンソール](https://developers.line.biz/console/)にアクセス
   - プロバイダーを選択または作成
   - 「チャンネルを作成」→「Messaging API」を選択
   - 必要情報を入力して作成

3. **LINEログインチャンネルの作成**
   - 同じプロバイダー内で「チャンネルを作成」→「LINEログイン」を選択
   - アプリタイプは「ウェブアプリ」を選択
   - 作成後、「LIFF」タブからLIFFアプリを追加

4. **Bockerへの設定**
   - 各チャンネルから以下の値を取得して入力：
     - LINEアクセストークン（Messaging APIから）
     - LINEチャンネルシークレット（Messaging APIから）
     - LIFF ID（LINEログインチャンネルから）
     - LINEチャンネルID（LINEログインチャンネルから）
     - LineユーザーID（予約通知用）

5. **保存**
   - すべての項目を入力後、「保存」ボタンをクリック

### 3-3. 予約設定

#### 設定項目と推奨値

1. **予約受付最大日数**
   - 今日を含めて何日先まで予約可能にするか（7〜90日）
   - 推奨: 30日
   - 繁忙期は60〜90日に延長することを推奨

2. **キャンセル可能日数**
   - 予約日の何日前までキャンセル可能か（0〜14日）
   - 推奨: 3日
   - 期日を過ぎるとシステムでのキャンセル不可

3. **予約間隔**
   - 予約枠の時間間隔（15/30/60/90/120分）
   - 推奨: 60分
   - 施術時間と予約間隔の大きい方が適用されます

4. **予約可能席数**
   - 同時間帯の最大予約数（1〜20席）
   - 実際の席数に合わせて設定

5. **最短の予約開始時間**
   - 当日予約で現在時刻から何分後以降を受付するか
   - 推奨: 30分

### 3-4. 営業時間

#### 営業日・時間の設定方法

1. **営業日の選択**
   - 各曜日をクリックして営業日/定休日を切り替え
   - 営業日は色付きで表示されます

2. **営業時間の設定**
   - **共通設定**: すべての営業日を同じ時間にする場合
     - 「共通の営業時間を使用する」をON
     - 開始時間と終了時間を選択

   - **個別設定**: 曜日ごとに異なる時間を設定する場合
     - 「曜日別設定」タブを選択
     - 各曜日の開始・終了時間を個別に設定

3. **保存**
   - 設定完了後、「営業時間を保存」ボタンをクリック

### 3-5. 休業日設定

#### 特別な休業日の設定方法

1. **カレンダーから日付を選択**
   - カレンダー上で休業日にしたい日付をクリック
   - 選択された日付は色付きで表示
   - 複数日選択可能（最大30日）

2. **選択の解除**
   - 選択済みの日付を再度クリックで解除

3. **保存**
   - 「保存」ボタンをクリック
   - 追加・削除された件数が表示されます

### 3-6. 決済設定（Stripe Connect）

#### Stripe連携の手順

1. **初回連携**
   - 「Stripeと連携する」ボタンをクリック
   - Stripeのオンボーディング画面へ遷移

2. **必要情報の入力**
   - ビジネス情報（店舗名、所在地、業種）
   - 運営責任者情報と本人確認書類
   - 振込先銀行口座情報

3. **審査と有効化**
   - 情報送信後、Stripeの審査（通常数分〜数時間）
   - 承認後、自動的にカード決済が利用可能に

4. **ステータス確認**
   - 連携状態は設定画面に表示
   - 「Stripeダッシュボードを見る」から詳細確認可能

## 4. 典型的な利用シナリオの例

### シナリオA: 新規開業時の初期設定
1. 基本設定タブで店舗情報を入力
2. 営業時間タブで営業日と時間を設定
3. 予約設定タブで予約ルールを設定
4. LINE連携を設定（任意）
5. Stripe決済を設定

### シナリオB: 年末年始の特別営業設定
1. 休業日設定タブを開く
2. カレンダーから12/31〜1/3を選択
3. 保存ボタンをクリック
4. 必要に応じて営業時間も調整

### シナリオC: LINE連携の追加設定
1. LINE公式アカウントを作成
2. 必要なチャンネルを作成
3. API設定タブで各種IDとトークンを入力
4. 保存して連携完了

## 5. エラー・注意事項

### よくあるエラーと対処法

#### 基本設定
- **エラー**: 「最大文字数を超えています」
  - **対処**: 入力文字数を制限内に収める

- **エラー**: 「画像のアップロードに失敗しました」
  - **対処**: 画像サイズを5MB以下にする、形式をJPEG/PNGにする

#### LINE連携
- **エラー**: 「LINE Channel IDは数字のみで入力してください」
  - **対処**: ハイフンや文字を除いて数字のみ入力

- **エラー**: 「認証に失敗しました」
  - **対処**: 各種トークン・IDが正しくコピーされているか確認

#### 予約設定
- **エラー**: 「予約間隔が施術時間より短く設定されています」
  - **注意**: 問題ではないが、実際の予約枠は施術時間に依存します

### 操作時の注意点

1. **保存前の画面遷移**
   - 変更内容は保存するまで反映されません
   - 他のタブに移動すると変更が失われます

2. **営業時間変更の影響**
   - 既存の予約には影響しません
   - 変更後の新規予約から適用されます

3. **LINE連携の順序**
   - 必ずMessaging APIチャンネルを先に作成
   - その後LINEログインチャンネルを作成

4. **Stripe連携の注意**
   - 一度連携すると解除には別途手続きが必要
   - 本人確認書類は鮮明な画像を用意

## 6. FAQ・補足

### よくある質問

**Q: 郵便番号を入力しても住所が自動入力されません**
A: ハイフンを除いた7桁の数字で入力してください。例：1234567

**Q: 営業時間を変更したのに予約画面に反映されません**
A: ブラウザのキャッシュをクリアするか、プライベートモードで確認してください。

**Q: LINE連携がうまくいきません**
A: 以下を確認してください：
- Messaging APIとLINEログインの両方のチャンネルを作成済みか
- 各IDやトークンを正しくコピー＆ペーストしているか
- LINEログインチャンネルでLIFFアプリを作成済みか

**Q: Stripeの審査にどのくらい時間がかかりますか？**
A: 通常は数分〜数時間で完了しますが、追加書類が必要な場合は数日かかることがあります。

**Q: 決済手数料はいくらですか？**
A: 売上の4% + 40円/件です。振込手数料と月額固定費は無料です。

### 補足情報

#### 設定変更の推奨タイミング
- 営業時間の変更：営業終了後
- 予約設定の変更：予約の少ない時間帯
- 休業日の設定：少なくとも1週間前

#### サポート連絡先
設定でお困りの場合は、画面右下のチャットマーク（💬）からお問い合わせください。

#### LINE設定の有料サポート
LINE設定が難しい場合、5,000円（税込）で完全サポートサービスを提供しています。詳細はAPI設定画面内のアコーディオンをご確認ください。
