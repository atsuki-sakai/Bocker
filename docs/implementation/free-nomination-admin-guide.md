# 指名フリー機能 管理者ガイド

## 概要

指名フリー機能は、顧客が特定のスタッフを指名せずに予約できる機能です。システムが自動的に最適なスタッフを割り当て、管理者は必要に応じてスタッフを変更できます。

## 機能の特徴

### 顧客側の体験
- スタッフ選択画面で「指名フリー」を選択可能
- 指名料は0円（追加料金なし）
- 予約確認画面では「指名フリー」と表示
- 実際に割り当てられたスタッフ名は非表示

### 管理側の機能
- 割り当てられたスタッフ名を確認可能
- フリー指名予約のみスタッフ変更が可能
- 変更履歴の追跡

## 画面説明

### 予約一覧画面

フリー指名予約は以下のように表示されます：

```
予約ID: R-20240120-001
顧客名: 山田花子
メニュー: カット＆カラー
スタッフ: 田中太郎（フリー指名）← 特別な表示
日時: 2024/01/20 14:00-16:00
```

### 予約詳細画面

#### 表示内容

1. **基本情報セクション**
   ```
   予約タイプ: フリー指名
   割り当てスタッフ: 田中太郎
   割り当て日時: 2024/01/20 10:30:45
   ```

2. **スタッフ変更セクション**（フリー指名のみ表示）
   ```
   [スタッフを変更] ボタン
   ```

3. **変更履歴**（変更があった場合）
   ```
   変更履歴:
   - 2024/01/20 13:00 管理者により変更
     変更前: 田中太郎 → 変更後: 佐藤次郎
   ```

#### スタッフ変更モーダル

スタッフ変更ボタンをクリックすると、以下のモーダルが表示されます：

```
利用可能なスタッフ:
□ 佐藤次郎（優先度: 5）
□ 鈴木三郎（優先度: 3）
□ 高橋四郎（優先度: 2）

[変更] [キャンセル]
```

## 操作手順

### スタッフ変更の手順

1. **予約詳細画面を開く**
   - 予約一覧から該当の予約をクリック

2. **フリー指名の確認**
   - 「予約タイプ: フリー指名」であることを確認
   - 通常予約の場合、スタッフ変更はできません

3. **変更可能なスタッフの確認**
   - 「スタッフを変更」ボタンをクリック
   - 該当時間帯で対応可能なスタッフが表示されます

4. **スタッフの選択**
   - 新しいスタッフを選択
   - 優先度が参考表示されます

5. **変更の実行**
   - 「変更」ボタンをクリック
   - 成功メッセージが表示されます

### 注意事項

- **変更可能な予約**
  - フリー指名予約のみ変更可能
  - 通常の指名予約は変更不可

- **時間制約**
  - 予約時間帯に対応可能なスタッフのみ表示
  - スタッフの勤務時間・休憩時間を考慮

- **優先度について**
  - 数値が大きいほど優先度が高い
  - 自動割り当て時は最も優先度の高いスタッフを選択

## トラブルシューティング

### よくある問題と対処法

#### Q: スタッフ変更ボタンが表示されない
A: 以下を確認してください：
- フリー指名予約であるか
- 適切な管理者権限があるか

#### Q: 利用可能なスタッフが表示されない
A: 以下の可能性があります：
- 該当時間帯に勤務するスタッフがいない
- 全スタッフが他の予約で埋まっている
- スタッフの勤務スケジュールが未設定

#### Q: スタッフ変更がエラーになる
A: エラーメッセージを確認し、以下を試してください：
- ページをリロード
- 時間を置いて再試行
- 別のスタッフを選択

### エラーメッセージ一覧

| エラーメッセージ | 原因 | 対処法 |
|---------------|------|--------|
| フリー指名の予約のみスタッフ変更が可能です | 通常予約での変更試行 | - |
| 利用可能なスタッフが見つかりません | 該当時間帯にスタッフなし | 予約時間の変更を検討 |
| スタッフの変更に失敗しました | システムエラー | 再試行または技術サポートへ |

## ベストプラクティス

### 運用上の推奨事項

1. **スタッフ優先度の設定**
   - 経験豊富なスタッフに高い優先度を設定
   - 新人スタッフは低めの優先度から開始
   - 定期的に優先度を見直し

2. **変更時の考慮事項**
   - 顧客の過去の利用履歴を確認
   - 可能な限り同じスタッフを維持
   - 変更理由を記録（システム外で管理）

3. **スタッフへの連絡**
   - スタッフ変更時は該当スタッフに通知
   - 顧客情報・施術内容を共有

### 分析・改善

1. **フリー指名率の確認**
   - 定期的にフリー指名の利用率を確認
   - 高すぎる場合はスタッフ指名の促進を検討

2. **スタッフ稼働率の確認**
   - フリー指名による稼働率の変化を分析
   - 偏りがある場合は優先度を調整

3. **顧客満足度の確認**
   - フリー指名利用者の満足度を調査
   - フィードバックを基に運用改善

## セキュリティとプライバシー

### アクセス制御
- スタッフ変更機能は管理者権限が必要
- 変更履歴は全て記録・保存

### 顧客プライバシー
- 顧客には割り当てスタッフを非表示
- スタッフ変更の事実も顧客には通知しない

### 監査証跡
- 全ての変更操作をログに記録
- 変更者・変更日時・変更内容を保存

## 今後の機能拡張予定

1. **自動最適化**
   - 顧客の過去履歴を考慮した割り当て
   - スキルマッチングによる割り当て

2. **通知機能**
   - スタッフへの自動通知
   - 変更時のアラート

3. **レポート機能**
   - フリー指名の統計レポート
   - スタッフ稼働率分析
