# サイト全体の配色統一デザイン

## 目的

Bockerの公開サイト、認証画面、予約画面、管理画面で異なる色名や16進数が直接使われている状態を解消し、用途から色を選べる共通カラートークンへ統一する。ライト／ダークテーマの双方で、サロン向けサービスらしい清潔感と落ち着きを保つ。

## デザイン方針

- ブランドの主役色は深いティールとし、見出し、主要ボタン、選択状態に使う。
- 暖色のコーラルはCTAや予約日のマーカーなど、視線を集める箇所だけに限定する。
- 成功、注意、危険、案内はそれぞれ `success`、`warning`、`destructive`、`info` を使い、緑・黄・赤・青の直接指定を残さない。
- 背景、カード、境界線、補助文字はニュートラルな意味別トークンを使う。
- グラフは共通のチャートパレットと軸・罫線・ツールチップ用トークンを使う。
- LINEなど第三者ブランドのロゴ色は、ブランド識別に必要な箇所だけ例外として維持する。

## 実装範囲

1. `app/globals.css` と `tailwind.config.ts` に必要な意味別トークンを集約する。
2. 共通UI、主要ページ、分析・トラッキング画面の直接色指定を意味別トークンへ置換する。
3. 言語一覧を一か所に集約し、日本語・英語・タイ語を常に同じ順序で表示する。
4. 現行画面とずれているFAQ、About、Pricing、Convex、料金変換のテストを修正する。

## 検証

- 言語セレクタにタイ語が表示され、タイ語ロケールへ遷移できること。
- 全ユニットテスト、型チェック、プロダクションビルドが成功すること。
- 公開トップ、認証画面、ダッシュボード、分析画面をライト／ダークテーマで目視確認すること。
